ReSlice is a simple audio slicing tool written in Python.

It was created to make preparing samples and breakbeats quick and straightforward by automatically dividing a WAV file into equal slices and exporting each slice as an individual audio file.

The project started as a way to learn Python and audio programming, and has grown into a lightweight tool for sample preparation.

## Features
Load WAV files
Display waveform
Adjustable slice count
Automatic equal slicing
Preview slices
Export numbered WAV files
Simple desktop interface

ReSlice is designed to be simple, fast and easy to understand while also serving as a learning project for Python GUI and audio development.

## Built With
Python
PySide6
SoundFile
SoundDevice
NumPy
Current Status

##Version 0.1
